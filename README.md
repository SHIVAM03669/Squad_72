# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/SHIVAM03669/Squad_72.git
```

Navigate to the project directory

```bash
cd Squad_72
```

Install dependencies *(if required)*

```bash
npm install
```

Run the project

```bash
npm start
```
